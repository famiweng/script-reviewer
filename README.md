## 🎯 设计哲学与解决痛点

在传统的剧本审稿 Prompt 中，将**错别字、空间站位、剧情因果、人物动机、台词潜台词、行业常识与政策审查**全部塞进同一个提示词，会导致大模型出现严重的**注意力稀释（Attention Dilution）**与**长文本中间遗忘（Lost in the Middle）**。

`script-reviewer` 采用**“三权分立 + 模块化分工”**的工业级设计：
- **物理场记归场记**：遵循中美工业剧本排版标准，严审空间几何、轴线视向、微观伤情演变与物理穿帮。
- **叙事因果归因果**：自适应匹配电影/长剧/短剧载体结构，严审查事件链条、信息差闭环、伏笔与钩子。
- **人物心理归心理**：聚焦欲望驱动、权力位阶博弈（Status Shift）、情绪节拍与四大“Show, Don't Tell”视听化重构。
- **制片合规归制片**：把关政策审查红线、行业垂直真实性、侵权融梗预警与制片预算黑洞。
- **总控大脑出白皮书**：聚合降噪、维护三大资产台账、支持多集增量合并，按 P0/P1/P2 输出权威行动路标。

## 🎞️ 项目载体自适应机制

技能库内置对不同影视形态的评判标尺切换：

1. **🎬 院线电影 (Feature Film · 90~120min)**：聚焦【三幕八部法】、【主题隐喻 (Theme)】、【A/B故事交织共振】与【灵魂黑夜 (Dark Night)】。
2. **📺 电视剧/网剧 (Series · 40~45min/集)**：聚焦【主副线交织推进】、【中点危机】、【多梯度集尾悬念钩子 (Cliffhangers)】与【长线人物弧光】。
3. **📱 竖屏微短剧 (Short Drama · 1~2min/集)**：聚焦【前3秒核心视听抓手】、【单集高频打脸反转】、【卡点付费停顿点 (Paywall Hooks)】与【即时情绪爽点】。

## 📊 三大核心资产追踪台账体系

在长篇或多集审查中，`script-review-lead` 会自动提取并维护三大核心台账，确保跨集资产零丢失：

### 1. 《伏笔与悬念回收对照表》
| 埋设场次 | 伏笔/悬念内容 | 预期回收线索 | 实际回收场次 | 闭环状态 |
| :--- | :--- | :--- | :--- | :--- |
| 第 1 集 第 3 场 | 抽屉里的半张旧照片 | 揭示生母身份 | 第 6 集 第 2 场 | ✅ 已闭环 |

| 道具名称 | 起始持有人 | 流转经历 (场次) | 最终状态 | 连续性核验 |

## 🔄 多集增量滚雪球审稿工作流 (Incremental Ledger Workflow)

面对 30~80 集长篇剧本，推荐采用**“增量滚雪球审稿法”**：

```
[第 1~5 集剧本] ──────► 生成【初始三大资产台账】 + 【第1~5集白皮书】
                                   │
                                   ▼
[第 6~10 集剧本 + 初始台账] ──► 生成【合并更新后台账】 + 【第6~10集增量白皮书】
                                   │
                                   ▼
[……持续滚雪球……] ─────────► 生成【全剧终审资产台账】 + 【全剧终审总白皮书】
```

**调用提示词示范**：
```text
请调用 script-review-lead 进行【增量审稿】：
- 【输入1：上一阶段资产台账】：（粘贴上一轮输出的三大台账）
- 【输入2：本期送审剧本】：第 6~10 集剧本
- 【目标】：合并更新三大台账，并输出本期增量白皮书。
```

## 🚨 分级审查标准 (P0 / P1 / P2)

| 级别 | 标识 | 定义与标准 | 处理策略 |
| :--- | :--- | :--- | :--- |
| **P0** | **🚨 致命硬伤** | • 触犯政策审查红线（不可过审/违规办案/历史虚无主义）<br>• 主线因果彻底断裂 / 机械降神<br>• 人设严重崩塌 (OOC) / 强行降智工具人<br>• 阻断拍摄级穿帮（已死之人复活、道具凭空瞬移、空间轴线对撞） | **必须修改**<br>拍摄或报审前必须清零 |

| **P2** | **💡 打磨建议** | • 潜台词留白与对白高级感提升<br>• 镜头化视听语言转化（小说描写镜头化）<br>• 制片降本增效（场景合并/精简转场）<br>• 格式标点与括号提示语规范排版 | **供主创斟酌**<br>尊重个人风格，锦上添花 |

## ❓ 常见问题与实战技巧 (FAQ)

### Q1：为什么各技能都强调“不干涉作者个人风格”？
> **答**：真正的专业审稿必须区分**“事实/逻辑硬伤”**与**“艺术风格选择”**。快节奏转场、荒诞幽默或留白是风格，不能当成错误挑刺。所有技能均设定了红线约束，只抓影响拍摄和理解的硬伤。

### Q2：面对不同题材（如仙侠 vs 刑侦），如何保证专业核查准确？
> **答**：`script-production-domain-expert` 会根据剧本题材自适应切换知识库。审刑侦时严格核查刑事诉讼法与公安规范；审仙侠/科幻时则切换为核查其内在世界观法则自洽性与特效制作预算风险。
